一个简单轻量的 AstrBot 插件，支持通过自定义关键词在群聊或私聊中随时唤醒机器人并触发 LLM 回复。

## 功能特性

- 无需艾特机器人，只要消息中包含设定的关键词即可唤醒大模型回复
- 支持群聊管理员指令动态添加、删除、查看触发词
- 配置实时持久化保存，重启不丢失
- 自动避开命令前缀，防止误拦截管理员指令

## 群聊指令

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `/触发 开` | 开启关键词触发功能 | `/触发 开` |
| `/触发 关` | 关闭关键词触发功能 | `/触发 关` |
| `/触发 添加 <词>` | 添加一个新的触发词 | `/触发 添加 meow` |
| `/触发 删除 <词>` | 删除指定触发词 | `/触发 删除 meow` |
| `/触发 列表` | 查看当前已配置的所有触发词 | `/触发 列表` |
| `/触发 状态` | 查看总开关与触发词详情 | `/触发 状态` |

## 配置项

支持在 AstrBot Web 管理面板的“插件配置”中进行可视化配置：
- `enable`: 是否开启关键词触发功能（布尔值）
- `triggers`: 触发词列表（字符串数组）
